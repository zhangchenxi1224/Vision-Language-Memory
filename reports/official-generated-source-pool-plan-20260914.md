# 下一轮训练的独立生成源图准备

03完整对照证明，清除错误既包括已有薄弱点，也包括继续训练后新增的退步。训练代码目前每个逻辑源状态只用一个固定源PNG；部署则把前一步实际生成PNG编码后继续写入。准备源图变化实验，检验训练条件覆盖是否不足。旧来源图交叉诊断只覆盖固定旧案例，不能排除更广的来源变化影响；这仍是待检验假设。

本次先登记训练材料生成，尚不启动优化。固定4f checkpoint `7294684170578dfc617b4fafcea97e6480c08642ca4f1e5967ff8966aa103182`、原生Base28步、CFG1、FP32 Writer及bf16 Reader。每次从官方灰色128图独立开始，用原训练bank中的gray→ambient/jazz/clear三条原始训练事件，各8个预先冻结的新噪声种子，共24张PNG。种子与既有19328训练噪声、开发噪声以及两套回归计划的显式噪声分离。完整计划为 [generated-training-source-pool-preregistered.json](official-alignment-results-20260913/generated-training-source-pool-preregistered.json)。

四张GPU各生成6张。Writer只接收原图、事件和噪声种子；状态名、gold token和五个问题只用于生成完成后的训练材料检查，不进入Writer条件。保存全部PNG、120条原始回答、实际生成噪声、29个采样状态及由实际PNG重新编码的source latent。收集器逐文件哈希，重新生成噪声，核验纯噪声初态、完整轨迹、全部case/问法及原始token+立即EOS。

任何一张图有任一问法失败，整个源图池都拒绝进入训练；保留全部失败，不筛选好图、不换种子重抽。通过只表示24张训练材料在原五问法上合格，不是新验证分数或新模型效果。单步生成源图也不能代表所有多步链来源分布。

若源图池合格，下一步为训练增加独立的source及其native event编码变体；必须从所选实际PNG同时得到官方VAE source与条件编码，不能仅换latent却保留旧图的条件。目标bank、独立高斯噪声、官方FM公式和全时间域保持原样。原151条件的完整baseline和开发评估仍用原上下文，保持可比性；训练初始化、预算、源图抽样和所有回归/新验收范围另行冻结。本文和生成计划都不代表下一轮优化已登记或已启动。

本地针对生成计划和全24图收集器的6项测试通过（7.61秒）：完整分路、全部原始问法、失败整池拒绝、缺失案例/替换问题/篡改实际噪声/缺失立即EOS拒绝。GPU真实生成尚须单独报告。
