# B/MCQ：直接训练真实递归状态（C730 / R730）

2026-09-26，依据用户最新指示实施。主线仍为单偏好视觉记忆 L0–L2，直接推进训练，不以新增归因探针作为启动前提。

## 本次改变

此前保持训练主要见到初写 PNG，评测却要求接收自身多次更新后的 PNG。本轮直接补上这种训练状态：当前 Writer 生成实际多步图像，再用这些图像训练下一步保持；经过固定数量更新后，重新生成训练图像。

I64 的完整结果支持把预算投入这里：pilot T1 第1轮匹配收益 C=46/128、I=59/128；第10轮 C=4/128、I=5/128。I 的短程优势没有延续成稳定十轮记忆。因此保留已完成 C/I64，**尚未启动的 I730 暂不执行，其 23,360 步预算改用于 R730**。C730 仍作为固定初写源图对照。两组总保持更新预算仍为 46,720 步，递归源图生成增加推理开销，不把它称为等算力比较。

该更改取代旧 `B_MCQ_CI730_IMPLEMENTATION_20260925.md` 中“随后启动 I730”的安排；已运行 B730、C64、Reader 不改代码、不打断。

## 两组定义

| 条件 | C730 | R730（本轮主实验） |
|---|---|---|
| 父模型 | 同一个 B730 固定第23,360步 | 相同 |
| 训练偏好 | 全部730条 | 相同 |
| 保持目标 | 原偏好的 B 教师 latent | 相同，给偏移状态提供语义锚点 |
| 保持输入 | 冻结父模型的 V0/V1×两噪声初写 PNG | 当前学生实际生成的深度0–9 PNG，分段刷新 |
| 初写/保持抽样 | 1:1 | 相同 |
| FM更新 | 23,360步，effective batch 4 | 相同，四段各5,840步 |
| 官方FM/推理 | 原生条件、float32、28步、CFG1 | 相同 |

C/R 比较的是“固定初写源分布”与“定期刷新、多深度学生源分布”这两种训练方式，不能再细分归因于刷新频率或深度覆盖中的某一项。两组所有问题仍由同一个冻结 Reader 读取。

## R730 固定训练流程

| 段 | 生成源图使用的权重 | 初写回复版本 | 本段优化步范围 |
|---|---|---|---|
| 0 | B730固定终点 | V0 | 1–5,840 |
| 1 | R730第5,840步 | V1 | 5,841–11,680 |
| 2 | R730第11,680步 | V0 | 11,681–17,520 |
| 3 | R730第17,520步 | V1 | 17,521–23,360 |

每段对730条训练偏好各生成一条链：灰图→初写 S0→S1→…→S9。每一步都是官方 Writer 推理，保存 uint8 PNG，重新打开并经官方 VAE/原生条件编码；跨步只传 PNG，不传上一步 latent。每段7,300张、四段29,200张训练源图，不按可读性删样本。

随后训练 `S_d + 第(d+1)轮无关交换 → 原偏好的教师 latent`，d=0…9；深度9的输入用于第10次保持。每条偏好每段16次保持曝光，十个深度均覆盖；另有16次初写曝光。全程每条偏好64次保持、64次初写，初写V0/V1各32次。保留初写训练，避免只优化保持而丢失写入能力。

段间保存并恢复 **同一个优化器状态、RNG和全局步数**，不是四次从头训练。新段源图来自上一段学生权重，缓存按该段图像内容独立绑定。训练噪声域为 `refresh-0`…`refresh-3`，与正式评测 `rollout` 噪声域分离。

这是交替生成源图与逐步FM训练，不是贯穿十轮采样的端到端反向传播。没有新增 Reader 语义损失，没有修改官方 FM 方程、模型结构或原生条件路径。

## 3+2 与最终判据

直接复用已经完成的730条 B 教师：同一 latent 由 T1/T2/T3 优化288次、选项持续轮换。教师不重做。Writer 的监督仍为这些目标 latent；Reader 问题和选项不会进入 Writer 输入。O1/O2 与 V2 不参与梯度、源图筛选或检查点选择。

只评估固定第23,360步终点。由最终权重**重新生成独立两噪声、十轮完整 PNG 链**，训练源图不作测试链。报告0/1/5/10轮：

- train730：全量T1，分母1,460条链；pilot64：同图T1/T2/T3/O1/O2，分母128；dev90：同图3+2，分母180。
- 匹配图相对错配/灰图的收益、同图两种OOD全对、两噪声都对、跨0/1/5/10的完整成功率。
- 64/90在0/10轮补齐已登记选项位置指标，不把位置鲁棒性检查变成训练启动前置。
- 保留初写失败样本。初写正确样本的保持率只作辅助分析；train/dev分开。

若 R 的5/10轮匹配收益提高，才能支持多步状态训练改善保持；训练损失或源图生成完成都不算成功。若 B730 的 dev 初写仍无图像收益，不能把 R 在训练偏好上的保持改善说成新偏好泛化。本轮直接解决训练状态覆盖缺口，但不预先承诺解决所有内容泛化问题。

原计划的最终官方180与单偏好覆盖评测继续在流程/终点冻结后执行；不扩展K2/K4，不恢复A或付费Judge。完成固定方案后归档并暂停自动跟进，不无限追加预算。
