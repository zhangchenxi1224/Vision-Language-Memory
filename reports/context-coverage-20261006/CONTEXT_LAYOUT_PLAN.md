# 固定 Writer 的历史排版敏感性诊断

冻结于 2026-10-06，任何本轮图片/评分产生之前。触发证据：32历史/256步在训练历史恢复特异性，但固定端点dev90没有恢复/应用的正匹配收益；完整dev报告通过独立复核后才部署本轮。不是继续dev选点。

假设：Writer 对历史语义的利用可能依赖训练时的角色标签格式。只改变Writer输入的角色标签与分隔换行，保留两条消息的角色、顺序及content字符串逐字节不变。标准为 `user: CONTENT\nassistant: CONTENT`；新格式为 `### user\nCONTENT\n\n### assistant\nCONTENT`。不增删回答内容，不改写偏好，不引入问题，不使用ARIS的省略assistant内容V1/V2。分词及位置变化是本实验因素的一部分，不能仅凭结果区分其细部原因。

固定 final32/256，SHA `5aaffb9983f2c16b176790237109502fc02516dda8a3e5c0ee9ecedba5f036a8`；同32训练历史、灰1024源图、原生28步/CFG1、原2噪声种子、RGB量化接口。无新训练、教师、dev或official180评分；不改变默认方案。标准布局64图及全部5376旧评分只读复用。

先用新生成包装器对冻结顺序首历史/seed0生成标准格式图片，要求与旧标准PNG SHA完全相同。失败立即停止并保留成本，禁止放宽为近似后继续。通过后生成新布局64图、1536行（32×12问×匹配/错配×2噪声）；复用5376行，总6912。384教师分布只读，缺失即失败；完整目标前缀、Reader绑定、图片/配置/源码哈希均核验。包含额外1张标准校准图，总新增65PNG。

原16/新增16分层，各独立n16；同分层同主题固定错配。先在每历史内平均4问×2噪声，再偏好级配对bootstrap95%区间。恢复、应用、中性分开报告标准和新布局的匹配、错配、灰图、文本。主要量为：新布局匹配KL−标准匹配KL（正为退化）、各布局错配KL−匹配KL（正为特异性）、标准特异性−新布局特异性（正为特异性损失）。四个恢复/应用×分层结果全部报告，不事后合并成显著结果。

若在同一格中匹配KL显著恶化且特异性显著下降，支持该格对角色布局敏感；若无此信号，只能说明此次扰动未检出退化，不能认定等价、泛化或定位全部原因。阳性后才冻结训练时布局增强这一单因素对照；阴性则另选训练侧机制，不追加本轮格式或dev搜索。无需把空白/文本对照重新跑一遍；文本KL=0是教师自一致性，不是文本准确率100%。

独立context-layout-20261006 checkout、context-layout-v1 output；旧执行树/输出只读。阶段累计上限1 GPUh，失败/校准/生成/读回共用，仍在总16 GPUh池（此前7.373056459228198）；最多同时2 GPU，每次≤6小时，共用保守deadline。启动前核验旧worker退出、owner撤销、GPU/内存/其他任务预留。全量源证据验收后部署；不空转保活，不动其他自动化。
