## 可重复验证命令

在仓库根目录使用Python 3.11或更新版本运行。下载约181MiB；解包与验证需数GB磁盘空间。只需CPU，不需要模型、CUDA或云实例。验证器先校验Release资产SHA，再使用其中冻结代码，不执行未经校验的远端代码。

```bash
python -m pip install numpy beautifulsoup4
gh release download prefeval-aug4x3-final-20261013 \
  --repo zhangchenxi1224/Vision-Language-Memory \
  --pattern 'prefeval-aug4x3-scientific-evidence-20261013.tar.gz' \
  --dir outputs/prefeval-release
python scripts/reporting/verify_prefeval_aug4_publication.py \
  --asset outputs/prefeval-release/prefeval-aug4x3-scientific-evidence-20261013.tar.gz \
  --work outputs/prefeval-release/verified \
  --receipt outputs/prefeval-release/verification.json
python scripts/reporting/build_prefeval_aug4_publication.py --check
```

Windows可将上述换行命令写成一行。仅重建表格不需要Release下载：

```bash
python scripts/reporting/build_prefeval_aug4_publication.py
```

完整复算核验原始分片SHA、唯一键和覆盖范围、冻结数据/种子/选项位置、错配供体、原官方解析器、原题文、存储正确标签及解析失败；重新计算各控制、诊断suite、偏好级配对bootstrap和official177。派生表与原完成CSV的352条控制记录逐项交叉核验。输出[本次验证回执](OFFLINE-VERIFICATION-20261013.json)。

运行代码基线：`b8d82be660db7ba0a14bcba68057e8cafccb186e`；运行时双卡adapter与共享池补充源码在证据包中。冻结数据SHA：`28cb15e49979970d6b3277db1dca198f9f6fd5b7c82bedbd217b627cb0e905e7`。上游MCQ源SHA：`b3088007724a5c4e21af80ed0220fa796e9f7473007ce9a7df4612eb7cd8f8ac`。

Git中本次原始汇总与完成指标CSV按 `-text` 保存，避免换行转换破坏证据哈希。旧B730的JSON属于历史Git文本文件，其来源SHA绑定Git中的LF字节；Windows工作副本的CRLF在生成来源清单时仅规范换行，不改变JSON内容。新生成报告统一UTF-8/LF；统计精度保存在JSON/CSV，Markdown显示四舍五入后的值。
