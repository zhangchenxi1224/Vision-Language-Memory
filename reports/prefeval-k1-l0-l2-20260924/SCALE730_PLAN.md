## 固定数据、监督与预算

- 使用已有官方训练侧 730 条。90 dev 与 180 official 不做教师优化或 FM 更新。
- A 仍为官方完整自然回答 token CE；B 仍为官方 MCQ XML token CE。
- 每状态 288 步，T1/T2/T3 各 96 步；B 每问法四正确位置各 24 步。
- 已完成的 64 条教师目标逐项核实并复用，不再追加梯度。只补齐其余 666 条：
  每组新增 191,808 步，最终每组总计 210,240 个目标优化步。
- T1/T2/T3 在复用的 64 条上与原执行提交 5153444 逐字一致。
  新状态使用已经预先准备的三问法；两组共享同一偏好和问法表。
- 两组共享 Writer 均重新从同一 4fbc857 父检查点开始，保持官方 FM、AdamW 参数、
  effective batch=4、28 步原生推理、CFG=1、RGB 输入输出不变。
- Writer 总计 23,360 步，每组 93,440 次采样，使每条偏好恰好出现 128 次，
  与 pilot 的每偏好曝光量一致。预先另存第 2,048 步模型，用于相同更新预算比较。

两个固定检查点都在原 64 条 pilot 子集与同一 90 dev 上做两噪声链单写 T1 MCQ。
空图/全文基线与首轮共用：模型、题目、选项顺序及无图像状态历史均未变。
另外直接读回全部 730 条教师图的 T1 MCQ，分开检查教师可读性与 Writer 蒸馏结果。
不按教师正确性筛数据，不按 OOD 选检查点。

23,360 步比较同时改变训练覆盖与总计算量，不能宣称为覆盖的单因素因果实验；
2,048 步比较保持总更新数相同，但每条偏好的曝光下降。两个结果分别报告。
当前自动入口推进至上述完整单写诊断；后续仍需基于证据完成换问法、自然回答、
RGB 保持及最终官方留出评估，不能把本轮单写部署作为整个目标完成。
