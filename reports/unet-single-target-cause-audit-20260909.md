# U-Net 单目标失败：证据与因果诊断

本报告针对 `fd07eb1-20260909-r01`，不把旧 77-target flow-matching 实验的诊断结果当成本轮已验证事实。

## 第一性原理

固定条件与噪声后，U-Net 生成器是一个函数 `z = F(theta)`。当前训练优化 `mean((F(theta)-z_target)^2)`，其参数梯度为 `2 J^T (z-z_target) / D`，其中 `J` 是生成终点对可训练参数的导数。

失败可能出在四个可区分环节：目标在当前 Reader/VAE 下已失效；训练与评测并非同一函数；梯度或优化有问题；可训练参数及目标函数不能有效消除影响答案的误差。一个非零梯度不能独自排除后三项，单次过拟合失败也不能证明完整 U-Net 不可学习。

当前仅更新注意力 `to_q/to_k/to_v/to_out.0` 的 LoRA；预训练 U-Net 基础参数约 3.900 亿，卷积、归一化等被冻结。冻结 U-Net 的可达集合与以后训练 U-Net 能达到的集合不同，不能用前者直接宣布后者不可能。

## 已有实验与本轮离线检查

- 96 个教师在当前解码/原问答路径上均严格正确并立即 EOS；这是同一道题的 96 个目标，不是 96 道题。
- rank 4 / 512、rank 16 / 512、rank 4 / 2048 在训练固定输入上均错误。多目标冲突不是发生失败的必要条件。
- 本轮 U-Net objective 是终点 latent MSE，QA 与 EOS 只用于评测。EOS 已进入教师制作链路，尚未作为这一阶段 U-Net 的训练损失；这是实验设计事实，不能直接等同于代码 bug。
- 完整检查 rank 4 的 2048 步和 rank 16 的 512 步：非有限指标均为 0，梯度裁剪次数均为 0。最大梯度范数分别 0.653、0.331，小于裁剪阈值 1。
- rank 4 最后 64 步平均 MSE 为 0.057589，比 1537–1600 步的 0.059513 仍低约 3.2%。不能宣称目标已完全收敛或简单梯度消失。
- 对 2048 步输出拟合最优逐通道 affine 映射后，RMS 仅从 0.240032 降至 0.238689（改善 0.56%）。整体通道尺度与平移不足以解释误差；不因此排除所有数据约定错误。
- Fourier 分析：残差能量 84.23% 位于径向频率 >= 0.25 cycles/latent-pixel 的高频带，低频 <0.125 的残差能量仅 4.82%。教师高频能量占比 14.23%，学生 2.56%。这说明此样本剩余误差主要在空间细节；是否这些细节导致 Reader 失败还需扰动评测，不能直接宣布因果。

## 已登记的最小 GPU 诊断

1. 原 2048 步 checkpoint 精确重放，核验与已保存 latent 完全一致；复核固定教师图像哈希及 QA。
2. 同一个函数在启用/关闭 activation checkpointing 时比较终点及参数梯度，再做中心数值差分。未通过则先修链路，不运行训练对照。
3. 沿学生到教师的单一直线插值，测试 alpha=0.5/0.75/0.9/0.95/0.99；对教师做两档低通平滑，再用相同原问、greedy decoding、32 token 和 EOS 规则评测。此实验只测这一方向，不能当成全局可读区域半径。
4. 比较终点 MSE 梯度与 QA+EOS 梯度在 latent 空间的夹角。
5. 从同一个 2048 步 checkpoint 起步，所有 arm 重置 AdamW、同一个固定噪声/目标，各运行 64 步：

| Arm | 可训练参数 | LR | Objective |
|---|---|---:|---|
| A1 | 原注意力 LoRA | 1e-4 | MSE |
| A2 | 原注意力 LoRA | 1e-5 | MSE |
| B1 | 全 U-Net（含已有 LoRA） | 1e-4 | MSE |
| B2 | 全 U-Net（含已有 LoRA） | 1e-5 | MSE |
| C | 原注意力 LoRA | 1e-4 | MSE + 0.1*(answer CE + EOS CE) |

VAE、Reader、condition encoder 仍全部冻结。对照使用相同原问答；另报两个固定测试噪声，不能用它们挑选 arm。OOM 记为缺失对照，不能记作科学失败。各 arm 保存独立权重、latent、原始输出和指标，绝不改写原始结果。

若 B 在匹配 LR 下明显优于 A，支持扩大可训练范围有帮助，但不证明 LoRA 永远不可行。若 C 的 QA 改善而坐标拟合没有同等改善，支持训练目标需要答题约束。若所有 arm 都未改善，还需继续区分优化与表示限制，64 步失败不能用于宣告不可能。

## 验证与部署

原采样器 16 项 CPU 合约测试通过。新增一个非线性、时间相关的 U-Net 数值测试，验证在所有输入冻结时，checkpoint 开关梯度一致、参数中心差分一致、负梯度小步确实降损；测试通过。真实模型上的数值检查仍等待 GPU。
