# 单偏好视觉记忆：截至2026-09-26晚的完整进度与结论

运行现场核对时间为北京时间21:29。本文汇总本任务各轮已完成实验、与其相关的历史结果和正在执行的C/R730。没有新增训练分支、推理或付费Judge；运行任务继续原流程。

当前证据支持：图像可以作为信息载体，共享Writer可以写入已训练的PrefEval偏好，部分信息能跨问法读出。仍未解决的是未训练偏好的可靠写入，以及5–10轮更新后的稳定保持。最新全量结果还说明，730训练偏好的初写本身也没有充分拟合，不能把问题只归为泛化。

## 数据和判据

官方1000条偏好中的820条训练侧划分为730训练、90同主题内部dev；另外180条留出主题保留为最终评测。pilot64是730的固定子集。730与180存在3条已披露的偏好/原题重复；最终报告180主分母，并另列177无完全重复记录。最终180视觉评测尚未开展，不能把dev90的两噪声180次读取称为官方180条测试。

冻结Reader为Qwen3-VL-4B-Instruct，VAE冻结。Writer沿用DreamLite官方FM和原生条件、28步CFG1；跨步保存/重读实际uint8 RGB PNG，再经VAE编码。没有传递上一轮latent。视觉存储、教师优化、3+2问法与本项目输入增强属于扩展，分数不等于完整官方PrefEval benchmark复现。

A教师使用完整自然回答CE；B使用轮换选项的MCQ短答案CE。教师对同一latent进行288次更新，T1/T2/T3各96次；O1/O2不参与本轮梯度、筛图或选点。O1/O2家族有历史暴露，因此不称从未观察过的全新OOD；同义问法也不证明新的语义用途。

匹配图和错配图使用相同题目/选项顺序。两者的正确率差用于观察内容相关图像收益；只看约40%的绝对准确率不足以证明记忆。128=64偏好×两噪声，180=90偏好×两噪声，1460=730偏好×两噪声；这些是重复测量。灰图/全文每偏好一次；pilot与train、V0/V1/V2不能合并为独立样本。

## 正在训练的C/R730实际改变了什么

C固定使用B730初写V0/V1×两噪声的2920张PNG；R用当前学生生成的多深度状态，并定期刷新。两组共享同一B730父权重、730偏好、原教师目标、1:1初写/保持、23360步官方FM。比较同时改变源深度和刷新方式，不能独立归因于其中一个因素；R增加生成开销，不称等算力实验。

R每段先生成730条S0…S9真实PNG链，再训练下一步：`S_d＋第d+1轮交换 → 原偏好的教师latent`。四段各5840步，源模型依次B终点、R5840、R11680、R17520。优化器、RNG、全局步数连续继承，不跨十步采样反传，也不筛掉错误源。

第0段7300PNG已经完整，5840步已正常完成。全部730偏好各16次初写、16次保持，保持深度0–9全覆盖。19:19开始以R5840生成第1段，21:29为两个分区各73条，共146/730完整链，含在途PNG735/733张。下一段银行齐备后才继续5841–11680步。

当前实例`prefeval-b-cr-h200x4-20260926`：GPU1运行C，GPU2/3生成R源图，GPU0空闲。原四卡遭平台回收后已在新实例恢复；当前进程、完整命令、GPU及日志正常。禁止实例未使用，其他实验未干预。

这已经在执行用户要求的“生成真实多步状态→训练下一步→用更新后的学生重新生成”。当前完成的是第一段训练和下一段刷新启动，不能提前宣称十轮保持改善。最终仍需C/R终点各自重新生成独立两噪声完整链，按730/64/90、0/1/5/10及3+2/位置指标报告。

## 目前可作出的实验结论

1. 任务内的视觉载体可读性已有强证据；B教师以及共享Writer训练侧的匹配图收益都支持这一点。
2. 共享Writer能拟合有限的已训练偏好；64条可达到128/128，扩展730后部分有效，但62.12%仍不可靠。
3. 未训练偏好写入尚未通过。dev90的3+2和V0/V1/V2均无稳定匹配图收益，不再只是早期训练快照的担忧。
4. 短程保持有证据，长期保持尚未通过。I延缓衰减，却没有解决十轮；当前R正直接补训练状态覆盖，效果待独立链检验。
5. PrefEval当前严格支持受限L0和部分短程递归；从灰图写入不同偏好不等于完成带旧记忆的overwrite/clear。PrefEval L1操作覆盖及可靠L2仍待证据，L3/L4不在本轮范围。

训练loss不能代替上述判据；训练源图完成不等于记忆成绩。R若改善已训练偏好的5/10轮保持，只能先证明该范围的保持改进，不能代替dev的新偏好写入成功。
