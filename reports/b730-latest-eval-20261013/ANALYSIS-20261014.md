# B730 最新协议补测：阶段结论

**本次补测把“新提问”与“新写入表达”分开后，暴露出B730的主要短板：已训练内容在原写入表达下仍可读回，换一种写入措辞后优势基本消失。AUG4低学习率组在表达变化下表现更好，但所有体系对未训练内容的可靠记忆收益仍未得到证明。** 这是固定93,440步终点和已核验阶段快照的结论，不代表四个checkpoint的完整补测已结束。

## 1. 任务链路解释

输入表达先经Writer生成RGB记忆图，再由冻结Reader结合问题读取答案。W0/T*保持原写入图像、只换问题；W*/T1则换输入表达重新生成图像、保留原问题。因此，B730在W0/T*仍达到91.15%，而W*/T1降到47.40%，支持其困难更集中于表达变化下的写入链路。该诊断不能进一步把问题唯一定位到文本编码、U-Net或latent目标，因为这些模块并未做单独干预。

## 2. 配对比较消除内容组成差异

同96个ID上，B730 W0/T1=93.62%，W*/T1=47.40%，写入表达变化下降46.22pp，偏好级配对95%区间[−54.69,−37.50]。P-L从93.10%降至72.27%，下降20.83pp；R-L从86.59%降至65.10%，下降21.48pp。比较使用每偏好2种子×4答案位置的均值，再对偏好采样，不把重复读回当作独立内容。

这些结果与“增强训练改善表达覆盖”的解释一致，但不是该解释的单独因果证明：B730有4f任务初始化及旧教师，AUG4的初始化、教师库和训练覆盖均改变。高学习率P-H/R-H接近对应控制水平，不能把其较小表达跌幅解释成较好的鲁棒性。

## 3. 新内容仍是独立未解决问题

B730在dev90的匹配−错配为−0.69pp，95%区间[−1.81,+0.42]；official177为−0.07pp，区间[−0.49,+0.42]。已训练内容的高准确率没有转化为明确的新内容图像记忆收益。P-L在新写入表达上的72.27%也不等同于新内容泛化，因为diagnostics96内容都参与过训练。

official180中已知三条内容/问题重叠过滤后，B730匹配准确率由36.18%变为35.10%，匹配收益由+1.18pp变为−0.07pp。应同时报告180和177，不能只保留较高结果。opposites16的错配图是原偏好供图，较大的匹配−错配差不等于反事实准确率很高：B730匹配准确率仅34.38%。

## 4. 下一步设计依据

优先完成其余checkpoint的同协议补测，检查写入表达跌幅是否随训练加深扩大，而不是按dev挑选中间模型。后续若检验增强本身，应固定初始化、教师、总曝光量、学习率及评测，只改变写入/提问覆盖；新内容和已训练内容改写继续分开。当前结果可以为多轮、模型自身起点的latent优化方案提供动机，但尚未检验该方案，不能据此宣称它会改善语义泛化。
