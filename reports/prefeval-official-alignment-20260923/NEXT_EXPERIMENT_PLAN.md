# 下一轮：官方任务监督对照 → 共享 FM Writer → 真实 RGB 记忆

2026-09-24。**本文件为训练前冻结的方案；当前执行进展以 `EXECUTION_LIVE.md` 为准。**
用户已明确选择两组并行：A 完整回答 CE，B MCQ 标签 CE；两组均使用三种同义训练问法，
另固定两种 OOD 问法仅作评测。本文件细化 `FM_ROUTE_CORRECTION.md`，优先于旧的
`WRITER_IMPLEMENTATION_PLAN.md` 中直接反传 28 步的提案。不使用 codex-with-chatgpt。

## 1. 实验要回答什么

要学的是一个共享更新函数：`M_t = Writer(M_(t-1), 当前对话交换)`。
未来问题只能进入 Reader，不能决定 Writer 写哪张图。持久状态只有实际保存、重新读取的 RGB。
同一张图换问法仍可用、换偏好能写入、持续写入能保持，才逐步构成视觉记忆证据。

首轮唯一方法对照是：**构造 target latent 时，自然回答监督与选择题监督，哪一种更有利于
共享 Writer 在未训练偏好上应用记忆？** 两组都做三问法增强；本轮不额外设置单问法第三组，
因此不能用本轮 A/B 差异声称测出了“三问法相对单问法”的因果收益。

Plan09 提供动机而非保证：V 相比 U，新问法恢复由 488/704 提高到 650/704，
原始 MCQ 却从 48/84 变为 47/84；K4 完整恢复仅 3/12。该轮还改变了应用监督接口，
不能把所有变化单独归因于问法增强。旧五问法在部分更早实验中全部用于教师训练，
也不能重新称为全研究过程未见的 OOD。
见 [原始结果](../prefeval-rgb-20260917/query-family-coverage-results.md) 和
`scripts/experiments/broader_writer_protocol.py::training_plan`。

## 2. 两组共用什么，区别在哪里

| 项目 | A：自然回答 | B：选择题 |
|---|---|---|
| 题意、三种训练问法、训练偏好 | 完全配对 | 完全配对 |
| Reader 问题 | 官方原题或等义改写 | 相同题干 + 官方四选项及指令 |
| 教师目标 | 官方发布的完整 `response_to_q` | 正确选项对应的 `<choice>C</choice>` 等完整短回答 |
| latent 损失 | 最终回答 token（含结束 token）的平均 CE | 完整短回答 token（含结束 token）的平均 CE |
| 被优化对象 | 每个训练状态一份 z_A* | 每个训练状态一份 z_B* |
| 第二阶段 | 用 z_A* 训练共享 Writer_A | 用 z_B* 训练共享 Writer_B |
| 统一评测 | 自由回答、官方 MCQ、OOD 问法、RGB 链 | 完全相同 |

Reader、VAE 均冻结。两组各有自己的 latent、Writer 和优化器；不混合 A/B loss，
不为三个问法各训练一个 latent。目标答案不进入 Writer 条件；A 不在训练时看到 B 的选项。
每条回答先按 token 平均，再按问题和活动偏好平均；不让长答案或新增槽自动占更大权重。
结束符只是一个普通答案 token，不沿用旧的 `answer_mean_CE + EOS_CE` 加权。
两组的 CE 数值不能直接比较优劣。

B 每次呈现选项时同步更新正确字母；原选项内容不改写。用固定随机种子打乱选项，
每 12 次更新覆盖三种问法 × 四个正确位置各一次，错项内部顺序也置换。
这样同一状态不会只对应固定字母。原始 MCQ 评分继续调用官方解析器；
选项标签 CE 用于训练是我们的适配，不是官方论文报告的 SFT 配方。

## 3. 三种训练问法 + 两种 OOD 问法

这是**应用问题的措辞划分**，不等于 PrefEval 的 explicit / implicit-choice /
implicit-persona 三种偏好披露形式，也不等于 0/5/10 轮干扰条件。
首轮训练显式偏好，保持官方完整 user/assistant 交换。

| ID | 用途 | 形式 | 构造原则 |
|---|---|---|---|
| T1 | 训练 | 官方原始问题 | 原文保留 |
| T2 | 训练 | 直接问句的等义改写 | 改词序、谓词及句法，不改任务 |
| T3 | 训练 | 指令式请求 | 将提问改成直接请求，同一答案仍充分回答 |
| O1 | 仅评测 | 情境陈述后接问题 | 陈述只能来自原题已有信息 |
| O2 | 仅评测 | 间接／条件式请求 | 改变表达结构，不引入条件或新的任务约束 |

以“推荐墨西哥城餐厅”为例（示意，不代表已完成全量问法数据）：

- T1：What restaurants in Mexico City would you suggest I try?
- T2：Which restaurants would you recommend that I try in Mexico City?
- T3：Recommend restaurants for me to try in Mexico City.
- O1：I'm deciding where to eat in Mexico City. Which restaurants would you suggest?
- O2：If I asked you to recommend restaurants to try in Mexico City, what would your suggestions be?

每个样本单独改写题干，不只在同一句原题外套五个提示前缀。五个版本的实体、地点、
时间、数量、否定、请求范围和答案集合必须相同。不得把隐藏偏好（例如“不吃辣”）
补进问题；不得改变选项、增添“解释理由”等使官方目标不再适用的要求。
若某个改写改变答案适用性，修正改写，保留原始目标；不能据模型答题成绩选择简单改写。

A 三个问法共用同一条官方自然语言目标。B 使用相同题干改写，共用官方选项内容，
仅随排列改变标签；官方 `<choice>...</choice>` 输出要求不随问法变化。
因此“问题增强”与“输出格式变更”不会混在一起。新增四个改写属于本项目扩展，
不能称为官方原题。原题 T1 的官方格式结果与改写结果分开报告。

训练以 T1→T2→T3 循环，每个状态始终更新同一个 z*；多偏好状态的所有活动类别等权。
完整问法清单在推理前落盘，记录 base_pair_id、题干、family、来源及 split。
O1/O2 不进入梯度、教师筛选、early stopping、checkpoint 选择或本轮超参数调整。
两个 OOD 家族用于开发侧和官方评估侧，题目具体文本不同；一旦开发侧结果被用于下一轮
方案调整，须标记为已观察的问法家族，不能继续声称新一轮的完全未见 OOD。

这里的 OOD 只指**问法分布外**，不自动证明新语义任务泛化。旧复述模板仅保留为
历史诊断；不把“原样复述偏好”重新作为本轮主要训练任务。

以 10 个干扰交换为保持阶段主条件；0/5 是同一完整链的诊断截面。

教师优化可使用训练答案，这是离线监督。上线写入时输入严格为“上一张 RGB + 当前交换”。

Reader 回答时只有最终 RGB 与当前问题；同一 PNG 回答全部五种问法和两类任务。

## 5. 第一阶段：有限预算构造目标图

先做 64 条 K1 训练偏好。每组每状态 **288 次 latent 更新**，T1/T2/T3 各 96 次，
64 × 288 = 18,432 次更新／组。288 是本轮为三问法及四选项位置均衡而提出的预算，
不是已有成功结果。A/B 从相同灰图 VAE 编码初始化，fresh Adam，起始 lr=0.05，
betas=(0.9,0.999)、eps=1e-8、weight_decay=0，沿用最初教师构造的学习率作固定起点。
发生非有限值则保存并报告失败；不只给失败的一组额外调参或追加步数。

梯度路径为 `z → frozen VAE decode → uint8-equivalent RGB → frozen Reader → answer CE`。
量化前向与 PNG 一致，反向用 STE 近似；它是有偏估计，最终必须实际 PNG 回读评价。
不改变 Reader/VAE 权重，不让答案梯度穿过 DreamLite 的 28 步生成器。
所有教师固定在最后一步，不用 OOD 或官方评估选择中间最优图。

每个状态的三问法损失共同约束一张图，而不是训练三张专答图片。
K1 无关干扰不改变本实验要保存的有效偏好，所以可以复用同一规范 z* 作为不同保持前缀的
目标；多偏好、覆盖和清除后状态改变时，再构造相应前缀目标。
失败目标、覆盖率和全部 64 条分母完整保留，不按评测成绩偷偷过滤教师。
保存 latent、实际 PNG 和原始回答后进入有限共享 Writer pilot，不无限优化教师。
两组更新数与问法曝光配对，答案长度不同，实际 token 数及 GPU 小时单独记录；不称等算力。

## 6. 第二阶段：共享 Writer 的官方 flow matching

两组均从 `4fbc857` Writer 权重开始，fresh optimizer，分别学习各自目标银行。
保留 Base native 条件、冻结 VAE/条件编码器、训练 full U-Net：

```text
x_sigma = (1-sigma) * z_target + sigma * epsilon
v_target = epsilon - z_target
loss_FM = MSE(v_theta(x_sigma, sigma; Encode(previous_RGB), current_exchange), v_target)
```

source 只在条件侧，不混入目标加噪桥。推理固定原生 28 步、CFG=1、纯高斯起点、
1024×1024 RGB，每次写入都重新生成实际图片。这里对齐官方 FM 目标和生成过程；
full-U-Net 与学习得到的 latent 目标仍区别于官方 LoRA 编辑微调。

首轮写入 pilot：每组 **2,048 次 FM 更新，effective batch=4**，共 8,192 次条件抽样，
64 条偏好各 128 次。使用已有 FM 起点 AdamW lr=5e-5、betas=(.9,.999)、eps=1e-8、
weight_decay=1e-4、clip_norm=1。A/B 配对事件、抽样顺序、sigma 和噪声种子；
目标图差异是监督方式的结果，不强求两组目标像素相同。固定终点后比较教师与学生。

保持阶段也先限定每组 **2,048 次 FM 更新，batch=4**。用上一阶段冻结 Writer 在
64 条训练历史上实际滚动写入 10 个干扰交换，保存每个前缀 RGB；这些学生源图用于后续
保持转移训练。抽样 1/2 初始写入、1/2 保持转移；偏好均衡，保持位置在 1…10 间均衡。
目标仍对应真实有效状态，不能因源图已遗忘而把错误结果当 gold。A/B 各用自己的生成源图，
构造方式与次数配对。完整链评估使用续训后的 Writer 重新生成，不能复用训练源图算成绩。

这两段预算是拟定的首轮有限实验，不保证收敛。若教师本身失败，记录教师瓶颈；
教师好而单写学生差，集中改 FM；单写好而保持链差，集中改连续写入。
不同时更换损失、Reader、采样器和数据。不得将教师图的好成绩代替学生成绩。

## 7. 所有端点使用同一套评测

先固定模型和 PNG，再跑下面的矩阵。主比较为 **90 条内部开发偏好上的共享 Writer**，
不比较训练 CE 的数值来决定胜负。原始题 T1 用于本轮方法选择，O1/O2 只作冻结后的报告。
180 条官方评估仅在流程及模型选择冻结后使用，不作为每个 pilot 的调参面板。

| 数据 | T1/T2/T3 | O1/O2 | 可以说明什么 |
|---|---|---|---|
| 64 条训练偏好，教师图 | 训练拟合 | 同内容换问法 | 教师可读性；不是新偏好泛化 |
| 64 条训练偏好，学生图 | Writer 拟合 | 同内容换问法 | FM 蒸馏差距 |
| 90 条开发偏好，学生图 | 已训练问法家族、新偏好 | 新偏好 + 未训练问法 | 共享写入和措辞迁移 |
| 180 条官方评估，最终模型 | 原题另报官方格式成绩 | 扩展问法成绩 | 固定流程最终报告，披露历史暴露 |

每格均报告自由生成的官方偏好遵循评价及 MCQ accuracy；各问法单列，并报告同状态
O1/O2 全对率，避免平均分遮蔽一个问法完全失败。MCQ 解析失败仍记错，另报格式失败率。
自然回答不作逐字匹配，不采用旧复述的严格字符串分数替代官方生成评分。
沿用官方 judge 提示及四项判断聚合；保存评判模型身份和原始结果。若官方评判模型不可用，
更换模型需单列“替代 judge”，不能把代理得分标为精确官方结果。
教师评判不回传离散 0/1 梯度，不引入额外 RL 流程。

同一冻结 Reader 跑完整文本、空图、错配图参照。文本参照是基线，不是数学上界。
原始生成按已对齐的 300 token 配置；MCQ 使用官方 prompt/parser。
Qwen 如需完整生成 `<choice>...</choice>`，必须给足完整短回答 token 预算并单独记录
模型适配，不能把官方某些模型的预填充 + 5 token 直接等同于完整 XML 的 5 token。
两组与参照共享相同生成配置，不事后延长某组的预算挽救错误。

0/5/10 干扰截面及两条固定噪声链均报告；相同记忆端点换五种问法时不能重写或再优化。
选方法以 T1 的开发集自由回答为主，同时检查 MCQ、记忆干预差值和保持能力；
若指标权衡或差异不明确，就如实报告未分胜负，不靠挑一项训练代理分数选赢家。
在扩容前，至少应看到共享 Writer 在开发侧两类任务上均优于空图及错配图；
“达到参照”只说明阶段性可行，不能提前称四槽视觉记忆完成。

## 8. 扩容与最终目标

首轮定位清楚后，沿同一两阶段主线扩展至 730 条训练数据和 K2→K4，不另起多条架构分支。
规模阶段的固定预算在 pilot 结果之后、启动之前记录，不能边看评估边无限追加训练。
保留 A/B 对照所得结论；只有证据明确时才选一路扩展，不能预设 MCQ 或长答案必然更好。

K2/K4 每个状态只有一张目标图，所有活动偏好等权、三问法轮换，OOD 两问法仍分开。
同义改写只测试措辞鲁棒性；多偏好阶段还需补充少量真正不同的应用问题，明确作为扩展数据，
才能测试同一偏好的不同用途，不能把五种同义句包装成五种语义能力。
各前缀目标按真实活动状态构造。覆盖后使用新偏好的答案；清除状态另设删除检查，
不能将取消前的 MCQ 正确选项继续当 gold，也不能擅自指定原四个选项中某个作为“无偏好”。

最终检查真实 RGB 链的新增、保持、覆盖、选择性清除，以及四个仍活动偏好的同图完整成功率。
单槽平均分不能替代 K4 全槽同时成功；清除后只剩三槽不能算四活动槽容量。
评估输入只有共享 Writer 生成的 PNG；不带优化器、隐式 latent 缓存或文本状态表旁路。
报告教师、FM 学生、递归学生三层结果，保留全部原始失败。
