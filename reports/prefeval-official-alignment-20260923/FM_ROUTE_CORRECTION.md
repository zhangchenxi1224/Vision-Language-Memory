2026-09-24。用户追问：两阶段训练已有一定效果，为何转向直接反传 28 步？
复核原始报告与官方代码后，主建议恢复为两阶段路线。
此前的直接答案梯度方案仅是未经实验比较的候选，不能因需要对齐 PrefEval 就替换已有 FM 主线。
本次只修正方案，没有开始新训练；730/90/180 划分和官方数据导出继续保留。

## 两种“步”

- **28 个生成步**：一次 Writer 写入内部，从新高斯噪声沿 Base 原生时间表走到输出 latent，
  然后解码成一张 RGB。这是一次图像生成，不是 28 次对话或 28 个独立记忆。
- **多次记忆写入**：对话 e1、e2、e3 分别触发 M0→M1→M2→M3，每次写入内部各有 28 个生成步。
- **中间写入监督**：监督完成 e1、e2 后应保留的状态，不是给每个去噪中间点出问答题。
  在两阶段方案中可实现为各前缀的目标 z1*、z2*、z3* 及对应 FM 转移样本，
  不需要让 Reader 的梯度穿过实际 Writer 的 28 步采样。

官方公开训练脚本随机采样 sigma，以目标 latent 与噪声插值，预测一个时间点的速度，
执行 MSE 更新。生成/评估时使用完整采样轨迹；训练并不要求每个样本都展开 28 步再反传。

## 为何保留两阶段路线

`2c5189a-latest-results.md` 记录：4f 原始功能矩阵 1790/1800、表达变化 1750/1800；
这些是已观察的历史回归结果，不证明 PrefEval 泛化，却证明已有目标状态蒸馏与共享 FM
训练在有限任务上可以工作。b62 没有进一步改善，也没有否定 FM 本身。

Plan12 的 M 在 PrefEval 教师图上的原始 MCQ 为 55/84、K4 完整恢复 2/12。
该阶段优化的是独立 latent，尚未训练 PrefEval 共享 Writer。这些失败不能归因于尚未进行的
PrefEval FM 蒸馏；至少存在目标状态语义可读性/绑定尚未解决的问题。

此前考虑直接答案梯度，是希望减少目标 latent 构造误差与 Writer 蒸馏误差之间的间隔。
这是合理的研究假设，但缺少对照证据，而且引入完整采样反传与量化近似等额外困难。
它不应成为本轮默认路线。

## 修正后的训练主线

### 第一步：以 PrefEval 下游任务构造视觉目标

对训练对话前缀所对应的有效偏好集合 S_t，构造一张共同目标图：

`z_t* = argmin_z mean_(q,a in Q(S_t)) CE(R(Q8(Decode(z)), q), a)`。

主监督按最新方案对照官方自然语言回答与官方 MCQ 标签；多偏好扩展目标明确标注。
同一个状态的多个应用问题共同监督同一张图，各类别等权；不能为每个问题单独造一个目标图。
写入之后的未来问题、答案只属于离线教师优化，不进入部署时 Writer 的输入。
复述继续作为辅助诊断，不让少量固定字符串替代主要语义任务。

教师目标必须检查实际 PNG 回读和未参与该次优化的问题；低训练 CE 不足以证明目标合格。
先在固定 64 条训练 pilot 上做有限目标构造，接着进行共享 Writer pilot，
同时报告教师表现和学生表现，避免长期只优化独立 latent 而没有 Writer 实验。
不要求用无限优化将所有教师变为满分；失败覆盖率、各阶段分母和训练纳入规则须明确保留。
尚不合格的多偏好目标不能被描述为已经成功的容量样本。

### 第二步：用目标 latent 训练共享 DreamLite Writer

保持已验证的官方 FM 形式：

`x_sigma = (1 - sigma) * z_t* + sigma * epsilon`

`v_target = epsilon - z_t*`

`L_FM = ||v_theta(x_sigma, sigma; Encode(previous_RGB), e_t) - v_target||^2`。

前一张记忆图及当前事件只作为条件，不能进入上述目标侧噪声桥。
source 总从上一张实际 RGB 编码，不能把教师优化器里的隐藏 latent 当作持久状态传下去。
保持 Base 原生推理时间表、纯高斯起点和已有 full-U-Net 参数更新选择。
这对齐官方 FM 目标与条件结构；full-U-Net、学习得到的目标和记忆任务仍是本项目适配，
不宣称是官方 LoRA 脚本所有配置的逐项复现。

### 第三步：以真实生成源图检验并训练连续写入

先比较同一任务上教师 PNG 与共享 Writer 输出的下游差距，再测试真实 RGB 写入链。
教师不可靠，改教师；教师可靠而学生失败，查 FM 蒸馏；单次写入可靠而连续链失败，
针对真实生成 source 的分布与状态保持处理，不同时改所有因素。

用学生生成的实际前缀 RGB 构造 source 转移样本时，对应 target 必须仍由该前缀的真实有效
状态定义。保留一个固定输出终点和全部失败，不把真实链失败用教师源图成绩替代。
所有评估只读取最终 PNG，无测试时 latent 优化，无文本状态表旁路。

## 现在保留和撤下什么

- 保留：官方 PrefEval 数据、对话及答案目标；语义组划分；现有 VAE/Reader、4f 起点、官方 FM
  训练器、原生 28 步推理、真实 RGB 链与多问题评估。
- 下一步重点：64 条 pilot 的新任务教师目标与共享 FM 学习，而不是另造 28 步可微训练器。
- 暂不作为主线：全 28 步答案反传、跨写入截断 BPTT、中间答案损失的 0.5/0.5 权重。
- 若两阶段训练已用对照隔离出具体瓶颈，再考虑直接答案微调是否值得研究。
