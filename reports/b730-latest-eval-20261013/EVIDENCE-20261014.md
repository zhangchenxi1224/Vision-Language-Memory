## 验证方法

在本仓库检出本次发布提交，安装CPU依赖 `numpy`、`beautifulsoup4`、`Pillow`。先下载Release资产并核对 `SHA256SUMS`，将证据包解压到本地目录，例如 `outputs/b730-evidence`。

```bash
python scripts/reporting/build_b730_supplement_publication.py --check
python scripts/reporting/verify_b730_supplement_publication.py --snapshot outputs/b730-evidence/partial-summaries-20261014-021530
```

第二条命令验证所有成员哈希、原始读回身份/完成回执、数据及代码绑定、唯一键和分母，再使用原始LF版官方parser、冻结bootstrap重新评分；要求每份summary逐字段完全一致。只依赖解压证据和本仓库代码，不连接Inspire，不运行GPU，也不需要模型张量或重新生成PNG。`--hashes-only`仅验证字节完整性，不能替代评分复算。

原始读回已记录生成PNG的SHA；此CPU复算不能证明远端PNG像素仍在或重新验证PNG推理本身。blank/text来源仍绑定AUG4 P-L原始控制checkpoint，未伪装成B730新推理。official177仅过滤已有official180读回。
