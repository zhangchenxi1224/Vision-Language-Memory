# 下一轮：仅用学生初写图学习一步保持

2026-09-24，启动前登记。此前完整 write-only 64 条链在第 5/10 轮已失去匹配图收益；
固定首例在 retain2048 后仍第一次更新失败，但其 B 图经原生 VAE 往返仍可正确读取。
一种待检验解释是：把已难以读取偏好的深层学生前缀用于恢复教师目标，增加了条件映射难度。
这不是“前缀 latent 已无信息”的证明；原完整保持结果仍待生成。

本轮保持 A/B、固定 64 偏好、各自 write2048 父权重、同一教师目标、同一 2,048 步预算、
每步 batch4、初写/保持各 4,096 次抽取、相同数据次序/噪声/sigma/优化器均不变。
唯一改变：保持抽取的输入图统一取该偏好的学生 `seed-0/prefix-00.png`，
而不取第 1—10 轮对应的深层前缀。仍轮换原位置的真实干扰交换，不把偏好文字补入输入。
全部 64 条都保留，不按照 Reader 成败挑选样本。该图经保存/reopen/VAE encode 后使用，
不能直接使用教师 latent、教师图或缓存文本历史作为旧记忆。

训练仍执行已有官方 FM 方程、原条件路径、原 target bank。
先检验从可用初始状态学习一步保持是否改善；这不等于已学会多步递归。
固定最终步数后从灰图重新生成每组 64 条、两噪声、0—10 轮完整链。
优先读取 T1 的 0/1/5/10，匹配和错配均报告，随后执行相同 90 条内部开发集。
已训练与未训练偏好分别列出；同一冻结 PNG 自然回答与 MCQ 分开统计。
不使用 OOD 来选择检查点、步数或本轮参数，不提前读取最终 180 条测试表现。

与原保持组比较需要明确：本轮改变了保持输入分布；即使改善，也只能支持这种输入课程有效，
不能仅凭改善断言先前失败只由信息丢失造成。初写性能退化同样报告。
本轮训练使用现有本任务 Reader 实例空余显存，不触碰禁用实例，不修改任何正在运行的代码工作树。
