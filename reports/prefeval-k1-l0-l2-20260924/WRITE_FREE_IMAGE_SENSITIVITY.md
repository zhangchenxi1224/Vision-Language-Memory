# 自然回答对图片有反应，不等于正确使用偏好

2026-09-24。使用固定 write2048 的完整 T1 自然回答，逐偏好、逐噪声链比较匹配图与错配图。
每对问题、提示、偏好评价依据及 300-token 预算一致，实际 PNG 哈希不同。
这里只比较完整生成 token 和解码文本，不使用未完成的开发集 judge 分数或 OOD 输出。

| 组别与数据 | 配对数 | 输出 token 完全相同 | 输出发生变化 | 变化对的公共前缀 token 中位数 |
|---|---:|---:|---:|---:|
| A，pilot64 | 128 | 0 | 128 | 0 |
| B，pilot64 | 128 | 0 | 128 | 7 |
| A，dev90 | 180 | 2 | 178 | 30 |
| B，dev90 | 180 | 3 | 177 | 43 |

解码文本完全相同的数量与 token 完全相同数量一致。两条噪声链是重复测量，
180 个配对不等于 180 条独立偏好。该分析说明自然生成对这些图片变化有反应，
不能把 [dev MCQ 几乎同答](WRITE_DEV_T1_RESULTS.md)外推为 Reader 在任何输出任务都忽略图片。

反过来，措辞或 token 改变也不证明图中有正确、可用的偏好记忆；它可能仅反映图像扰动对生成的影响。
仍需看同图匹配/错配的正确率、未训练内容和递归保持。此前 pilot 的自然回答优势不足结论不变，
开发集完整评分仍在进行，不能用本表替代准确率。
