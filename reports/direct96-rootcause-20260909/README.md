# Direct96 → U-Net 失败归因：空白回退与基础拟合障碍

本次在既有实验上做代码审计、制品核验和 CPU 张量分析，新增 optimizer update 为 0。未重新训练，也未调用 Reader 生成新答案；文中 QA 来自对应实验保存的真实 generation。数值证据见 [tensor-diagnosis.json](tensor-diagnosis.json)。

## 最明确的新发现

同一批 8 个评测噪声上，512 步蒸馏后的学生几乎回到灰色源图 latent：到 source 的 RMS 为 **0.013614**，参考正确终点到 source 的 RMS 为 **0.304541**。学生终点到训练目标加权均值仍有 RMS **0.085545**，所以不能直接称它为精确的目标均值。

构造一个零训练对照：从相同起点沿直线回到 source，按实际四步 sigma 取状态。该对照不读取成功库，终点就是已测过的 blank 控制；原问不能答对。

| 相同 8 个起点上的方法 | 对应参考终点的 MSE | 参考路径蒸馏总损失 | 原问 EM |
|---|---:|---:|---:|
| 零训练：回到 source | 0.0927453 | 0.1098249 | 0/1，原有 blank 控制 |
| 512 步 U-Net 蒸馏 | 0.0927732 | 0.1099120 | 0/8 |

这里的总损失与训练定义相同：终点 MSE 加前三个生成状态 MSE 的平均。MSE 均在八个起点上配对计算；返回 source 的算法给八个起点都返回同一 blank，原始 QA 控制分母仍为 1，不能复制为八个独立控制。

**学生在固定评测上的坐标目标甚至没有超过“不写入”的控制。** 原问 8 次全部输出 `No music preference recorded.`，均正常 EOS。这与输出退回空白 latent 的观测一致。比“8 个输出彼此相似”更具体的失败描述是：当前学生主要学成近似不写入。

## 不能把问题只归结为多目标冲突

本次发现并核验另一组已经完成的单目标实验。数据 SHA 与本次蒸馏相同，anchor 是 `direct-gaussian-s00-a1`；固定一个普通 Gaussian 输入噪声与一个正确终点，只优化真实四步最终 latent MSE。代码 `fd07eb1c21091bfd7044d77cf821cb5010b06ac1`。

| 可训练模块 | 更新数 | 固定训练输入 EM | 新噪声 EM | 训练输入的终点 RMS 误差 |
|---|---:|---:|---:|---:|
| attention LoRA rank4 | 512 | 0/1 | 0/8 | 0.265011 |
| attention LoRA rank4 | 2048 | 0/1 | 0/8 | 0.240032 |
| attention LoRA rank16 | 512 | 0/1 | 0/8 | 0.250509 |

三组的初始训练误差均为 0.326076；rank4 的 2048 步是在 512 步基础上恢复 optimizer 继续训练，rank16 从原始模型初始化。每组冻结审计通过，参数变化非零。2048 步使训练误差进一步下降，但测试误差由 0.297781 增至 0.310711；不能把单个例子的变化当作一般统计定律。

这些结果已经排除了“只因 96 个目标冲突”“只是 512 步太短”“rank4 改成 rank16 即可修复”作为充分解释。它们尚未证明任何 LoRA 都不可行，也未证明全量微调一定成功。

上一次汇报建议先做单目标检查，但该检查其实已由独立任务完成。这次已补齐记录，下一轮不应原样重跑这三组。

## 第一性原理：两个优化问题不能等同

Direct 优化直接调整 z 的每个坐标，通过 VAE 和 Reader 的 answer+EOS 反馈寻找一个功能正确的点。三种训练问法轮换发生在这里。

Writer 的变量是参数 theta，其输出为 `z_hat=G_theta(source,event,noise)`。局部参数更新产生的输出变化近似为 `delta_z = J_theta * delta_theta`。可改变的方向、幅度与优化条件取决于网络与可训练模块，不能因为直接调整 z 有解，就推断冻结基础权重、只更新 attention LoRA 的 Writer 容易拟合。

参考算法每次推理读取全部 96 个真实目标，计算条件均值速度。它的 8/8 说明在这些起点和四步积分条件下有一条可计算的成功路径；不能证明学生的可训练模块和优化预算足以实现该路径。

这版蒸馏优化的是坐标和路径误差，QA 训练权重为 0。若完整复制正确终点，QA 自然也会正确，所以“没有 QA 项”并不构成蒸馏必败的数学理由。但是，当学生只能近似复制时，坐标误差下降没有机制保证误差优先落在不影响答案的方向上。三问法+EOS 对 teacher 有效，不等于学生已直接接受三问法+EOS 的训练反馈。

## 从哪里开始偏离

固定 8 个评测噪声，逐状态比较实际保存的轨迹：

| 已执行生成步数 | 训练后学生与参考状态 MSE |
|---|---:|
| 0（起点） | 0，逐位一致 |
| 1 | 0.0001426 |
| 2 | 0.0102057 |
| 3 | 0.0410684 |
| 4（终点） | 0.0927732 |

学生完成了前段噪声收缩，却没有跟上后段写入。参考场在起点对 96 个目标等权；第一步后，对最可能目标的平均后验概率已达 97.88%，再之后为 100%。这说明参考映射含有很快的目标选择过程；它增加多目标模仿的难度，但不能解释已经失败的单目标实验全部现象。

最后的学生输出方差仅为参考输出方差的 **0.1103%**。最终配对 MSE 可精确拆成中心误差 0.0177076 与中心化误差 0.0750656，总计 0.0927732；说明新噪声应对应的目标差异基本没有被复制。

有限数据下，若模型没有学会噪声到目标的对应关系，常数预测在平方损失下的最优值是目标均值。当前老师大多围绕同一灰色 source，近似回到 source 就能取得低于很多随机输出的误差。本实验确实停在这样的低信息输出附近。但这不是说 flow matching 或 MSE 理论上必然导致均值塌缩：足够精确的对应映射本可以把损失降至零，单目标情况也不存在多目标取平均问题。

## 拟合不足集中在哪里

用二维正交 FFT 分解空间频率，并以同频段目标能量归一化，避免仅因高频格点更多就把误差占比误判为难度。高频定义为 `max(abs(fx),abs(fy)) > 0.25` cycles/latent-pixel。

在单目标 rank4、2048 步的固定训练样本上：

- 高频占全部残余坐标误差的 **79.34%**。
- 低频误差/目标能量为 15.67%，中频为 24.01%，高频仍为 **83.95%**。
- 生成的高频能量仅为目标高频能量的 **12.83%**。

rank16、512 步也显示相同方向，高频归一化误差仍为 89.20%。这支持当前学习方案更易拟合大尺度结构、难以复制精细编码的判断。**它尚未证明高频缺失是 QA 失败的唯一原因**：需要对同一 teacher 做滤波/细节恢复等干预，再运行 Reader。不能凭频谱直接认定“答案全藏在高频”。

## 归因边界与下一项最小检验

已确定：失败在成功终点向 Writer 输出的迁移；单目标拟合仍不足；多目标蒸馏近似退回空白 source；后段轨迹和精细结构没有学好；当前坐标损失不能代替功能验收。

尚待区分：可训练模块的限制、优化条件与损失侧重各自贡献。有限非零梯度只排除整体没有梯度，不能代替真实模型上的方向有限差分检查，也不能排除梯度条件较差。

下一轮应保留同一个固定噪声/正确目标，不增加题数或目标数：

1. 核验真实四步 rollout 的梯度与有限差分一致，并测更新对缺失残差的作用。
2. 在相同初始化与预算下，仅改变可训练模块，检查加入空间/输出模块是否打破高频拟合障碍；把 attention-only 作为对照，不预言全量微调会解决。
3. 另立坐标监督加三问法轮换 QA+EOS 的功能对照，明确这是学生侧训练反馈，比较训练样本的 raw EM、EOS、坐标误差。
4. 单目标实际能答对之后，再恢复多噪声、多成功区域与事件变化实验。单目标是诊断门槛，不替代最终多分布研究目标。

上述新 GPU 干预尚未执行；本次没有把建议当作已证明的修复。
