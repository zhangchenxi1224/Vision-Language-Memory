# U-Net 方案审计：目标分布、训练路径与功能监督

本报告审计当前 `train_latent_bank_unet.py`，不把设计建议记为已部署实验。第一轮实际结果与短程干预见 [失败排查](unet-failure-diagnosis-20260909/README.md)。

## 当前到底实现了什么

首轮主实验是独立抽取噪声与成功 endpoint 的 source-anchored conditional flow matching：rank-4 attention LoRA、512 次更新、每次一个 teacher/噪声/sigma、部署四步。随后另做同一旧权重下 64 步 FM 与 64 步完整 rollout QA+EOS 的诊断，两者仍为原问 0/8。

有 EOS 教师审计、冻结/哈希检查、几何统计、原问/改写/blank/donor 评测。没有已验证的模式划分，没有根据局部可读性选择区域代表，没有让几何结果改变训练配对或权重，也没有针对多个阶段的逐级可学性门槛。

`geometry_description()` 刻意不推断 cluster 数；`balanced_draw()` 均匀抽取训练 teacher。两者之间目前只是“统计之后继续运行”的关系。因此本版实现的是成功样本集合的生成基线，尚未完成“发现规律后设计类别/区域监督”这项研究工作。

## 第一性原理：功能目标与分布目标不同

令 `z_hat=G_theta(source,event,epsilon)`。任务的首要目标是让 `Reader(VAE(z_hat),question)` 正确输出答案并结束，同时随事件内容改变。在同题上，任何稳定可读的 latent 都可以是功能上的解。

成功集合 `Z_i+` 是优化算法在选定起点、分布、尺度和预算下找到的有限样本。其样本频率受搜索与筛选程序影响，不自动等于所有正确 latent 的自然概率分布，更不是已知语义类别。若目的仅是答对，不必先均匀复现全部 77 个坐标；若要研究多个模式，则另报覆盖、稳定性与多样性，不能与答案准确率混成单一目标。

原问正确是成员进入旧 bank 的标准，不代表所有成员对改写、扰动、序列化等都稳定。未来做 robust teacher 筛选时，使用事先划分的训练/验证问法与扰动；不能用最终测试问法筛选 teacher 后继续宣称那些问法是未见泛化。

## 独立配对的正确数学解释

设源 latent 为 s，均匀抽取 teacher z_j，epsilon~N(0,I)，起点 y=.5*s+.5*epsilon。当前桥接满足：

```
x_sigma = z_j + 2*sigma*(y-z_j)
        = sigma*s + (1-2*sigma)*z_j + sigma*epsilon
v_target = (y-z_j)/.5 = (x_sigma-z_j)/sigma
```

因此固定 sigma>0 时，`x_sigma | j` 是均值 `sigma*s+(1-2*sigma)*z_j`、协方差 `sigma^2*I` 的高斯。由有限 bank 可以直接求后验权重：

```
w_j(x,sigma) ∝ exp(-||x-sigma*s-(1-2*sigma)*z_j||^2/(2*sigma^2))
v_Bayes(x,sigma) = (x-sum_j w_j*z_j)/sigma
```

这是当前独立配对目标下的条件均值速度，不是预先指定某个 teacher 的作弊直线速度。在 sigma=.5 时，输入中完全没有抽中哪个 teacher 的信息，w_j=1/N，最优预测是平均速度；此时样本级 MSE 存在不可约项 `4*mean(||z_j-z_mean||^2)/D`。

**需要修正上一份报告对残差的解读**：起点附近的原始 target MSE 包含随机配对带来的条件方差，不能全算成模型未拟合误差。更合适的诊断是 `||v_model-v_Bayes||^2/D`，以及沿实际 rollout 的偏差。

这不意味着 MSE 必然把最终输出平均成一个点。中间状态能携带 teacher 信息，条件权重随状态改变。FM/CFM 的关系见 [Flow Matching for Generative Modeling](https://arxiv.org/abs/2210.02747)。对有限容量与少步生成，独立配对可能增加学习难度；保留边缘分布的 minibatch 配对是可检验的替代，见 [Multisample Flow Matching](https://arxiv.org/abs/2304.14772)。这些理论不替代本实验测量。

## 训练样本与部署轨迹的差别

现在的输入尺度、source 拼接、时间单位与积分方向已经核验一致。仍然存在另一个层面的差别：训练状态来自人工连接 teacher 的桥，部署状态来自模型前一步的输出。在速度学准的理想极限两者可以一致；有限模型的误差可能把后续状态推离训练覆盖区。仅拟合桥上的单步速度，不能直接观察这个累计偏差。

因此应同时检查：桥上误差、模型自身轨迹上的速度误差、实际四步终点到正确样本/区域的距离、终点原始 QA。任意中间图本身不必可读；直线路径经过不可读点不是训练错误，终点能否可读才是当前功能要求。

## 其他实验设计缺口

| 缺口 | 当前事实 | 必须区分的解释 |
|---|---|---|
| 未做最小可学性门槛 | 一开始就学 77 个目标，rank=4、512 次更新 | 单个目标都难拟合，还是多目标/多噪声联合学习才失败 |
| 目标的鲁棒区域未知 | 成功均值与抽查中点会失败 | 独立正确点、稳定区域、可组合模式不能混称同一种监督 |
| 分布研究未进入学习设计 | PCA/距离统计不改变成员采样 | 发现类别后监督，与直接拟合经验混合分布是不同的实验 |
| 只有一个 Direct 事件/答案 | 新噪声、改写都属于同一道 ambient 题 | 即使未来全部答对，也可能只是固定写出 ambient；不能证明按事件写入 |
| Frozen 的可达性信息未用于当前 FM 配对 | FM 对两条 bank 都重新抽普通噪声，只用成功 final latent | 在优化过的 xT 上可达，不等于普通新噪声也可达；原 xT 与轨迹可作为单独蒸馏对照 |

对 Frozen 路线，使用 `(优化后 xT, z_final+)` 的原始配对时，必须明确输入已经经过答案梯度搜索。这是可达性/配对学习对照；如果部署只允许普通新噪声，不能把该对照的成绩当部署成绩。

## 按信息增益排序的后续方案

以下均是建议，尚未执行；不同时改变所有因素。

1. **单输入、单目标的实际 rollout 拟合**：固定一份普通噪声和一个已复测正确的 teacher，仍完整四步生成，训练最终 `z_hat` 拟合该 teacher，同时记录原始 QA。先回答 U-Net 在现有可训练模块下能否写出一个已知正确目标。仅训练输入成功不算新噪声泛化。
2. **多个普通噪声、同一目标**：只放开噪声，检查目标生成能否稳定。第一步失败时，分别改变预算与 LoRA rank/可训练模块；保留同条件对照，不同时扩大两者。
3. **多个成功目标**：前两步通过后，比较当前独立配对与保留噪声/teacher 边缘分布的固定或 minibatch 一对一配对。代表目标必须选已验证成员，不能把未验证的均值作为正确标签。若引入模式索引，它须在部署可采样或由输入确定，不能仅训练时给 teacher ID。
4. **在真实生成终点联合检查结构与功能**：比较 FM、实际 rollout 终点拟合、终点拟合+QA/EOS；必要时再加 FM 辅助项。系数用验证集确定，不把一次 64 步 QA 失败解释成该目标无效，也不预言一个公式可以直接解决。
5. **至少两个反事实事件**：同一实体/属性只改变答案内容，例如 ambient 与 jazz，固定 source 和噪声，看 Writer 是否随事件改写。随后再扩展多题和未见事件。blank/donor 检查图像使用，事件交换检查 Writer 是否读取条件，两者不能互相替代。

## 本次新增零更新诊断

脚本 `scripts/analysis/diagnose_empirical_bank_flow.py` 与 `EmpiricalBankFlow` 对同一旧 bank 的 77 个训练成员计算闭式参考速度场，使用与旧 Writer 相同的 8 个新噪声和四步积分，再由原始 VAE/Reader 实测。

同时比较已训练 U-Net 与参考速度在参考轨迹、模型自身轨迹上的差异，并报告条件方差，避免把不可约误差误判为未学习。

该对照推理时访问完整 teacher bank，不是训练得到的 U-Net，不代表未见题泛化，也不保证四步恢复整个目标分布。其用途仅是检查相同起点/目标/步数下是否能得到正确终点。

四项 CPU 测试已通过：后验与直接高斯密度一致、条件均方误差分解、单目标四步终点、teacher 排列不变性。

### 真实 GPU 结果：参考速度场 8/8，旧 U-Net 0/8

2026-09-09 **01:19:18 北京时间**完成。执行代码 `6aca8abca4f45427483df7bf573eb1e32ba8e31a`，零次参数更新。原始证据：[empirical-bayes-flow.json](unet-failure-diagnosis-20260909/empirical-bayes-flow.json)。

77 个训练 teacher、8 个与旧评测完全相同的新噪声、相同 sigma=.5/.375/.25/.125 四步积分，参考速度场的八张生成图全部原始输出 `ambient` 后 EOS；终点逐位等于 bank 中的成功成员，共访问 **5 个不同成员**。没有手动指定各噪声应选哪个 teacher，也没有在最后把输出硬替换成最近 teacher；代码只执行四次速度更新。

这证明该 bank 与普通起点在这 8 个噪声下存在可运行的四步策略；不能把失败归结为四步本身绝对到不了正确终点。该策略生成时访问完整 bank，因此不是 U-Net 学会了，也不证明均匀复现 77 个模式。

起点的不可约样本速度 MSE 为 **0.409510**；下面直接比较 U-Net 与条件均值参考速度的差异，已经排除该条件方差项。数字为八个噪声的平均：

| sigma | 在参考算法轨迹上，U-Net 与参考速度的 MSE | 在 U-Net 自己的轨迹上，两者 MSE |
|---|---:|---:|
| .500 | 0.01779 | 0.01779 |
| .375 | 0.66680 | 0.66756 |
| .250 | 1.14002 | 1.62806 |
| .125 | 1.49292 | 7.04604 |

观测表明：起点接近条件均值速度，后段差异明显，且最后一步在模型自身状态上的差异更大。支持把研究重点放到**后段速度拟合与实际生成轨迹的误差积累**。这仍不能区分参数容量、训练覆盖与优化预算的独立贡献。

### 由这项结果得到的具体改进候选

除上面的单目标门槛外，现在可以建立一条有实测正对照的监督路线：

```
普通噪声 + 事件
    → 训练时访问该事件的成功库，计算参考四步轨迹和终点
    → 用同一噪声让 U-Net 四步生成
    → 拟合对应的参考终点，并检查原始 QA/EOS
```

同一噪声对应确定的参考轨迹，避免每次独立随机重新分配终点。在学生自己生成的中间状态上，也能查询参考速度，形成针对实际偏离位置的监督。推理时仅运行学到的 U-Net，不能读取 teacher bank。

建议分开比较三项，避免堆叠后失去归因：原始独立配对 FM；参考路径/终点蒸馏；参考蒸馏加模型自身轨迹上的速度监督。QA+EOS 作为功能指标贯穿，并另立联合损失对照。不要仅用 velocity MSE 宣称学生复现了参考算法。

参考算法只在目前 8 个噪声通过。新训练噪声产生的参考终点也须验证；若不是已验证成员且没有通过 Reader，就明确记为参考路径失败，不偷偷替换、不忽略失败覆盖率。其 teacher 访问频率未必均匀，若研究模式覆盖，应单独定义覆盖目标与公平采样协议。

此改进候选已形成可复用的参考算法代码，但**尚未执行 U-Net 蒸馏训练**，不能报告为修复成功。
